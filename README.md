# סטודיו קוד — אתר שיווקי (אתר סטטי)

האתר החי: https://danielaver.github.io/studio-code-website/

מה יש כאן:

- אתר השיווק של הסטודיו בשורש (`index.html`) — RTL, עברית, בלי תלות ב-CDN.
- `demos/` — 18 דמואים לפי סוג עסק (נבנו מקומית מהתבנית של כל קטגוריה).
- `demos/index.html` — עמוד גלריה שמרכז את כל הדמואים.
- `sitemap.xml` + `robots.txt` — מפת אתר מלאה לכל העמודים הציבוריים.

## יצירת קשר

באתר אין מספר טלפון מפורסם. הפנייה היחידה היא טופס יצירת קשר; הטופס שולח את
הפנייה ישירות ללוח של הסטודיו, עם שדה מקור (`utm_source`) כדי לדעת מאיזו רשת
הגיעה. כל עוד הדשבורד והמנהרה רצים הפנייה נרשמת מיד בלוח.

## פרסום

האתר מתפרסם אוטומטית ל-GitHub Pages (`python tools/publish-site.py`), והכתובות
מוגשות למנועי החיפוש דרך IndexNow (`python tools/indexnow.py --submit`).
כל שירות אחסון סטטי אחר יעבוד גם הוא — אותה תיקייה בדיוק.

אין סודות, מפתחות או מידע על לקוחות בתיקייה הזו — רק נכסים סטטיים.
