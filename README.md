# ערכת פרסום — סטודיו קוד (אתר סטטי)

מה יש כאן:

- אתר השיווק של הסטודיו בשורש (`index.html`) — RTL, עברית, בלי תלות ב-CDN.
- `demos/` — 18 דמואים לפי סוג עסק (נבנו מקומית מהתבנית של כל קטגוריה).
- `demos/index.html` — עמוד גלריה שמרכז את כל הדמואים.

## לפני פרסום — שני דברים לעדכן

1. **פרטי קשר אמיתיים.** כרגע באתר יש placeholders (`hello@example.co.il`,
   `050-0000000`) ובכל דמו `demo@example.co.il`. ב-`script.js` יש בלוק
   `STUDIO = { whatsapp, email }` — עדכנו אותו, ואת הפרטים ב-`index.html`.
2. **טופס יצירת קשר.** באתר סטטי אין שרת, ולכן אין `leadsApi`. במצב הזה
   הטופס נופל אוטומטית לקישור וואטסאפ עם כל הפרטים שהלקוח מילא — כלומר
   הפנייה עדיין מגיעה אליכם, רק לא נכנסת אוטומטית ללוח הניהול. כדי שתמיד
   תיכנס ללוח: להריץ את הדשבורד (`python tools/dashboard-server.py 8134`)
   ולחבר את האתר דרך טונאל ציבורי, או להחליף את הטופס בשירות טפסים חינמי.

## פרסום חינם

- **GitHub Pages** — דחיפת התיקייה לריפו ציבורי והפעלת Pages על הענף `main`.
- **Netlify Drop** — גוררים את התיקייה הזו ל-app.netlify.com/drop.
- כל שירות אחסון סטטי אחר (Cloudflare Pages וכו') — אותה תיקייה בדיוק.

אין סודות, מפתחות או מידע על לקוחות בתיקייה הזו — רק נכסים סטטיים.
